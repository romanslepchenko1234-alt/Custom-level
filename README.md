# Custom Level Row

Мод для Geode: в «Main Levels» после официальных уровней появляется страница с «+».
Вводишь ID, и уровень игрока добавляется в ряд, его можно сразу запускать.

## Как получить файл .geode без установки Geode SDK

1. Создай бесплатный аккаунт на github.com.
2. Создай новый репозиторий и загрузи в него ВСЁ содержимое этой папки
   (вместе со скрытой папкой `.github`).
3. Открой вкладку **Actions** и дождись зелёной галочки (5-10 минут).
4. Открой завершённый запуск и скачай архив **Build Output** внизу страницы.
5. Распакуй его и положи файл `.geode` для своей платформы в папку `geode/mods` игры.
   Мод также можно установить через раздел модов в самой игре.

## Перед загрузкой

В `mod.json` замени `yourname` в полях `id` и `developer` на свой ник.
